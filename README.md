파이썬 콘솔 퀴즈 게임 프로젝트

1. 프로젝트 개요
- 터미널에서 동작하는 나만의 퀴즈 게임을 처음부터 끝까지 직접 구현하는 프로젝트입니다.
- 파이썬 기본 문법과 클래스를 활용해 코드를 구조화하고, JSON 파일 저장을 통해 데이터를 유지합니다.
- Git을 통해 기능별 커밋과 브랜치를 관리하며 협업의 기초를 다집니다.

2. 퀴즈 주제와 선정 이유
- 주제: 개발 학습 복습용 퀴즈 ('터미널', 'Git', '도커' 및 '파이썬' 기초)
- 선정 이유: 미션 1에서 배운 '터미널', 'Git', '도커'와 미션 2에서 배우는 '파이썬' 클래스, 'JSON' 개념을 직접 문제를 풀며 복습하기 위해 선정했습니다.

3. 실행 방법
- python game_manager.py

4. 기능 목록
- 메인 메뉴: 퀴즈 풀기, 퀴즈 추가, 퀴즈 목록, 점수 확인, 종료
- 퀴즈 풀기: 등록된 퀴즈를 풀고 정답 여부와 최고 점수 비교 및 갱신
- 퀴즈 추가: 새로운 문제, 선택지, 정답을 직접 입력하여 등록
- 퀴즈 목록: 등록된 모든 퀴즈 목록 조회
- 점수 확인: 최고 점수 확인 및 미풀이 상태 안내
- 파일 저장 및 불러오기: 퀴즈 목록과 최고 점수를 'JSON' 파일로 저장 및 복원, 오류 시 기본값 복구

5. 파일 구조
- game_manager.py: 게임 전체 흐름, 메뉴, 점수, 파일 입출력을 담당하는 'QuizGame' 클래스 정의 및 실행
- quiz.py: 개별 퀴즈 데이터와 정답 검증을 담당하는 'Quiz' 클래스 정의
- quiz_data.py: 초기 기본 퀴즈 데이터 정의
- main.py: 'QuizGame' 실행 진입점
- 'state.json': 퀴즈 목록과 최고 점수가 저장되는 데이터 파일

6. 데이터 파일 설명 ('state.json')
- 경로: 프로젝트 루트 디렉터리 ('./state.json')
- 역할: 게임 내 퀴즈 목록과 최고 점수를 'UTF-8' 'JSON' 형식으로 저장하여 재시작 시에도 데이터를 유지하고, 파일이 없거나 손상된 경우 기본 데이터로 복구
- 필드 구조:
{
  "quizzes": [
    {
      "question": "문제 내용",
      "choices": ["1번", "2번", "3번", "4번"],
      "answer": 1
    }
  ],
  "best_score": 5
}

7. 커밋 및 저장소 정보
- 원격 저장소: 'https://github.com/kimdohee19/python.git'
- 커밋 기준: 기능 및 단계별로 분리하여 10개 이상 커밋했습니다.
- 커밋 메시지 규칙: 작업 요약이 드러나도록 작성했습니다.

8. 브랜치 및 저장소 복제 실습
- 브랜치 및 병합: 'main' 브랜치 외 기능 브랜치를 생성해 작업한 뒤 'main' 브랜치로 병합했습니다.
- 저장소 복제 실습: 별도 디렉터리에 'git clone' 후 변경 사항을 'commit' 및 'push'하고, 기존 작업 디렉터리에서 'git pull'로 반영 내용을 확인했습니다.

9. 코드 구조 및 클래스 설계 이유
- 클래스 구성: 'Quiz'와 'QuizGame' 두 개의 클래스를 정의했습니다.
- 메서드 분리: 입력 처리, 게임 진행, 파일 저장 및 불러오기 등 기능별로 메서드를 나누어 작성했습니다.
- 클래스 활용 이유: 개별 문제 데이터와 정답 검증은 'Quiz'가, 전체 게임 진행과 메뉴·점수·파일 입출력은 'QuizGame'이 맡도록 역할을 나누어 코드를 읽기 쉽고 수정하기 편하게 구성했습니다.

10. 요구 변경 시 수정 대상
- 점수 계산이나 메뉴 흐름을 바꾸고 싶을 때: 'game_manager.py'를 고치면 된다.
- 문제 구조(보기 개수, 정답 방식 등)나 기본 문제를 바꾸고 싶을 때: 'quiz.py'와 'quiz_data.py'를 고치면 된다.
- 저장되는 파일 위치나 형식을 바꾸고 싶을 때: 'state.json'과 'game_manager.py'의 파일 저장·불러오기 부분을 고치면 된다.
